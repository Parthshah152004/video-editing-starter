# Video Editing Starter

A ready-to-run video editing setup for Claude Code on Windows: Premiere Pro and After Effects
connectors, local AI tools (transcription, voice/music split, cut-outs, interpolation, upscaling),
HyperFrames graphics, fonts and a one-command installer.

It comes with an EMPTY style guide (`STYLE.md`): you teach it your own style.

- Setup: [`kit/SETUP.md`](kit/SETUP.md), then run `kit\setup.ps1`.
- Entry point for the assistant: [`CLAUDE.md`](CLAUDE.md).
- Bundled open-source parts and their licences: [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md).
